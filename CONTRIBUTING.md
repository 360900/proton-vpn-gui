# Contributing

Pull requests and issues are welcome. Please note that this project has no access to Proton VPN's internal APIs — it can only do what the public `protonvpn` CLI exposes.

## AI-Assisted Contributions

Contributions written with the help of AI tools are welcome, provided the contributor has reviewed the output and takes responsibility for it. All code — regardless of how it was produced — must comply with the coding conventions in [AGENTS.md](AGENTS.md). AI-generated code that bypasses those conventions will be asked to be revised before merging.

## Branching and Pull Requests

- All pull requests should target the `dev` branch, not `main`
- The `main` branch is reserved for stable, tested releases
- Pull requests submitted to `main` may be retargeted to `dev`
